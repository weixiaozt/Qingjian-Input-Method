## 开启

在「设置 → 输入」将拼音选为「关（只用形码）」，形码选为「五笔86整句测试」，打开「五笔连续整句」。
在「设置 → 云服务 → 本地翻译」打开「候选自动翻译」（此开关也用于五笔整句），选择已运行的本地模型。
在「设置 → 候选」将拼音行位置选为「只在候选窗口」，避免部分聊天软件残留行内编码。

## 输入和确认

- 连续输入 `wqjywyg`，候选为「你是谁」。
- 中文状态输入英文单词后，单击 `Shift` 原样上屏字母并保持中文模式；例如 `hello` → `Shift` → `hello`。没有中文候选时也可使用。需开启「设置 → 中英文 → 英文模式」及「切换键 → 单击 Shift」；没有未确认内容时，`Shift` 切换中英文。
- 连续输入 `wygdghtfdghkgawf`，候选为「今天下午三点开会」。
- 输入中不因满四码自动上屏；方向键移动整句高亮，数字键选择该编号整句。
- 短按 `Space` 确认整句中文；长按 `Space`（默认350毫秒）确认中文、换行和英文，光标停在中文末尾（换行之前）。
- 译文未到时长按会等待，`Esc` 取消等待并保留编码。再次 `Esc` 清除输入。
- `Enter` 确认整句中文，不发送聊天消息；无完整候选时保留编码供修改。
- 切换窗口取消尚未确认的编码，避免把五笔字母写入正文。

第一版最多96个字母、12个候选，首选仍可能有歧义。可以选其他整句候选，或修改编码再试。实验台的点击分词锁定界面尚未接入系统候选窗。

## 字词编码提示

开启候选的编码显示后，单字和码表中的词组显示五笔编码，例如「你[wqiy]」「今天[wygd]」。优先使用已配置的反查码表；没有反查码时显示该字词命中的编码。

由多个字词自动拼出的整句不显示编码，也不显示编码分隔线。编码只作为候选旁的提示，不会进入中文、译文或上屏结果。普通五笔和原有混输中的形码字词候选同样遵循此设置。

## 切回普通输入

关闭「五笔连续整句」恢复普通形码按键规则。使用普通五笔时可将形码选回「五笔（86）」。
使用拼音时将形码关闭、拼音选为「全拼」；已有拼音自动翻译功能保持可用。

光标定位功能需要重新打开目标软件以加载新版输入法。未重开的软件仍可双语上屏，但光标暂时保持原来的英文末尾位置。

## 长按右 Ctrl 切换方案

可在「设置 → 快捷键」开启「长按右 Ctrl 切换拼音/五笔」。单独按住默认600毫秒后松开，即在全拼整句和五笔整句之间切换。正在输入时会提示先确认或取消，保留原编码。详见[切换说明](sentence-scheme-switch.md)。
