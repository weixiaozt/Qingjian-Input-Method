## 开启

在「设置 → 输入」将拼音选为「关（只用形码）」，形码选为「五笔86整句测试」，打开「五笔连续整句」。
在「设置 → 云服务 → 本地翻译」打开「候选自动翻译」（此开关也用于五笔整句），选择已运行的本地模型。
在「设置 → 候选」将拼音行位置选为「只在候选窗口」，避免部分聊天软件残留行内编码。

## 输入和确认

- 连续输入 `wqjywyg`，候选为「你是谁」。
- 连续输入 `wygdghtfdghkgawf`，候选为「今天下午三点开会」。
- 输入中不因满四码自动上屏；方向键移动整句高亮，数字键选择该编号整句。
- 短按 `Space` 确认整句中文；长按 `Space`（默认350毫秒）确认中文、换行和英文。
- 译文未到时长按会等待，`Esc` 取消等待并保留编码。再次 `Esc` 清除输入。
- `Enter` 确认整句中文，不发送聊天消息；无完整候选时保留编码供修改。
- 切换窗口取消尚未确认的编码，避免把五笔字母写入正文。

第一版最多96个字母、12个候选，首选仍可能有歧义。可以选其他整句候选，或修改编码再试。实验台的点击分词锁定界面尚未接入系统候选窗。

## 切回普通输入

关闭「五笔连续整句」恢复普通形码按键规则。使用普通五笔时可将形码选回「五笔（86）」。
使用拼音时将形码关闭、拼音选为「全拼」；已有拼音自动翻译功能保持可用。
