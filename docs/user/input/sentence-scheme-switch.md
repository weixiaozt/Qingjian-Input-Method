---
title: 长按切换拼音与五笔
order: 13
description: 单独长按右Ctrl并松开，在拼音整句和五笔整句之间切换。
---

在「设置 → 快捷键」开启「长按右 Ctrl 切换拼音/五笔」。默认按住600毫秒后松开，切换一次；长按时长可调。

- 在青简输入框中单独按住右侧 `Ctrl`，松开后提示「已切换：拼音整句」或「已切换：五笔整句」。
- 切换在全拼和五笔86整句之间进行，并进入中文输入状态；上次选择会保存。
- 短按不会触发方案切换；原有中英切换设置保持不变。
- 按住期间使用其他按键、鼠标点击或滚轮会取消方案切换，保留组合操作。
- 有未确认的编码、翻译或候选时，先确认输入或按 `Esc` 取消，再切换；不会自动提交或清空文字。
- 切换后，自动翻译、短按中文、长按双语、中文末尾光标和字词编码提示继续使用原来的设置。

切换的是全局输入方案，其他应用会跟随。支持Windows新版输入法；安装后需重新打开应用以加载新版DLL。
虚拟机等软件仍可能自行处理右Ctrl，此功能不保证消除应用自身的所有按键行为。
