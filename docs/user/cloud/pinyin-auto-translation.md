---
title: 拼音候选自动翻译
order: 6
description: 拼音词语与整句自动英译，短按空格上屏中文，长按空格上屏双语。
---

在设置 → 云服务 → 本地翻译中打开「候选自动翻译」，填写已运行的本地服务地址和模型。
默认地址 `http://127.0.0.1:11434/v1`，模型 `translategemma:4b`。不需要启用云联想。

- 输入拼音词语或整句，短暂停顿后自动翻译当前高亮的中文候选。改拼音、选词或切换候选会更新译文。
- 短按空格：松开时确认中文，不必等待翻译。
- 长按空格：默认按住 350 毫秒，确认「中文＋换行＋英文」。一次按住只确认一次。
- 长按时译文还没好：候选窗显示等待，译文完成后上屏；Esc 取消等待并保留组句，再按 Esc 沿用原有清空行为。
- 翻译失败：保留原来的拼音，可短按空格继续输入中文。
- 先选定的部分中文仍参与后续整句翻译。长按选择较短候选时只提交已选部分，其余拼音继续组句。

确认仅写入输入框，不发送消息。换窗口或输入框会取消待提交翻译。密码及私密输入不翻译。
适用于全拼、双拼，以及开启[五笔连续整句](../input/wubi-sentence.md)后的五笔候选；普通五笔、注音、英文和普通空格保持原来的输入方式。
单行输入框是否保留换行由目标应用决定。

「双语长按时长」可调为 200–1500 毫秒。高级配置见 [配置文件](../advanced/config-file.md)。

此开关独立于原来的快捷整句翻译。安装新版后需重新打开目标应用；尚未重开的应用继续使用原来的空格行为。
