# Windows 快捷整句翻译

原文正常上屏，快捷键启动最后一句的异步翻译；不改变五笔字词上屏逻辑。取句依据应用提供的真实文本，不累加键盘事件。

原文快照绑定 TSF 上下文、光标锚点和原文范围。等待/预览态只有翻译键与模式键被特殊处理；其他输入取消预览并继续原键行为，Esc只取消。确认动作只带请求编号和译文，不能降级成普通光标插入。旧请求、失焦、输入变化或无法读取原文时禁止写入。

默认双语模式，其他模式为只看预览与英文替换。两组快捷键独立可配置；模式改变不重复翻译。不支持的应用保持原文，不通过模拟退格猜测范围。

首次本地模型加载允许60秒等待，不阻塞输入；有错误显示失败提示，用户关闭后可重试。使用 TranslateGemma 单用户消息格式；只有手动操作触发请求。模型输出保持预览，专业术语仍需用户核对。

验证包括句子边界、三种模式、反复触发、延迟返回、失焦、旧DLL兼容与设置持久化；真实应用验收须使用配套构建的Server和DLL。
