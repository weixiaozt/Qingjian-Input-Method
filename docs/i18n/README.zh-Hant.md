# Windows 雙語整句輸入實驗專案

本專案是基於[青簡 Qingjian](https://github.com/qingjian-team/qingjian) 的非官方衍生專案，由 weixiaozt 維護定制修改。與上游作者及團隊無隸屬關係，不代表其發布或背書。

Windows 定制版加入拼音／五筆整句候選的本機自動英譯、短按空格提交中文、長按空格提交雙語、長按右 Ctrl 切換方案，以及獨立五筆實驗台。模型權重與個人設定未包含在原始碼中。
