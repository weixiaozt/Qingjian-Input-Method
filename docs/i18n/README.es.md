# Proyecto experimental de entrada bilingüe para Windows

Este es un proyecto derivado no oficial de [Qingjian](https://github.com/qingjian-team/qingjian). weixiaozt mantiene las modificaciones. No está afiliado al equipo original ni cuenta con su respaldo; no es una publicación oficial.

La versión personalizada para Windows añade traducción automática al inglés de candidatos Pinyin/Wubi mediante Ollama local, pulsación corta de Espacio para insertar chino, pulsación prolongada para insertar ambos idiomas y cambio de modo manteniendo Ctrl derecho. Incluye un laboratorio Wubi independiente. No incluye los pesos del modelo ni la configuración personal.
