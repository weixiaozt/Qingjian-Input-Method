# Windows バイリンガル文入力実験プロジェクト

本プロジェクトは [Qingjian](https://github.com/qingjian-team/qingjian) を基にした非公式の派生プロジェクトです。独自の変更は weixiaozt が保守しています。上流チームとは独立しており、公式リリースでも、上流が承認した製品でもありません。

Windows 向けに、ローカル Ollama によるピンイン・五筆の文候補の自動英訳、Space の短押しによる中国語入力、長押しによる二言語入力、右 Ctrl の長押しによる方式切替、および独立した五筆実験ツールを追加しています。モデルの重みと個人設定は含まれません。
