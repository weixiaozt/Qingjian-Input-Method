# Windows Bilingual Sentence Input Experiment

This is an unofficial derivative of [Qingjian](https://github.com/qingjian-team/qingjian), with custom changes maintained by weixiaozt. It is not affiliated with, endorsed by, or released by the upstream team.

The Windows custom version adds automatic English translation of Pinyin/Wubi sentence candidates using local Ollama, short Space for Chinese, held Space for bilingual text, and held right Ctrl to switch input schemes. It also includes an independent Wubi experiment. Model weights and personal configuration are not included.
