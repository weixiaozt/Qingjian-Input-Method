# Experimentelle zweisprachige Satzeingabe für Windows

Dieses Projekt ist eine inoffizielle Ableitung von [Qingjian](https://github.com/qingjian-team/qingjian). Die Anpassungen werden von weixiaozt gepflegt. Es besteht keine Zugehörigkeit zum ursprünglichen Team; dies ist weder dessen offizielle Veröffentlichung noch eine von ihm bestätigte Ausgabe.

Die Windows-Anpassungen ergänzen automatische englische Übersetzungen von Pinyin-/Wubi-Satzkandidaten über lokales Ollama, kurzen Druck auf die Leertaste für chinesischen Text, langen Druck für zweisprachigen Text und langes Drücken der rechten Strg-Taste zum Umschalten. Ein eigenständiges Wubi-Testprogramm ist enthalten. Modellgewichte und persönliche Einstellungen sind nicht enthalten.
